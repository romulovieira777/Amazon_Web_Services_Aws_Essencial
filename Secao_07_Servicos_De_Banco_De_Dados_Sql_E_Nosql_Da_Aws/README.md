## Seção 07: Serviços de Banco de Dados SQL e NoSQL da AWS 🗄️☁️

Nesta seção, o foco é entender os principais serviços de banco de dados da AWS, cobrindo cenários relacionais (SQL) e não relacionais (NoSQL), com ênfase em **Amazon RDS** e **Amazon DynamoDB**.

### 💥 Conteúdos abordados nesta seção:

- **01 - Introdução aos Serviços de Bancos de Dados da AWS**
  - Visão geral dos serviços gerenciados de banco de dados na AWS.
  - Diferenças entre modelos **SQL** e **NoSQL**.
  - Critérios iniciais para escolher o serviço ideal de acordo com o tipo de aplicação.

- **02 - Fazendo uso de Banco de Dados SQL com RDS na AWS**
  - Conceitos fundamentais do **Amazon RDS**.
  - Benefícios do uso de bancos relacionais gerenciados (provisionamento, backup, atualização e alta disponibilidade).
  - Casos de uso comuns para workloads transacionais e aplicações que exigem consistência relacional.

- **03 - Fazendo uso de Banco de Dados NoSQL com DynamoDB na AWS**
  - Fundamentos do **Amazon DynamoDB**.
  - Características de escalabilidade, baixa latência e modelo chave-valor/documento.
  - Cenários indicados para aplicações modernas com grande volume de dados e acesso em alta performance.

### 🎯 Objetivo de aprendizado

Ao final desta seção, você deverá ser capaz de:

- Diferenciar bancos de dados **SQL** e **NoSQL** no contexto da AWS.
- Entender quando utilizar **Amazon RDS** ou **Amazon DynamoDB**.
- Reconhecer vantagens de serviços gerenciados para reduzir esforço operacional e aumentar a confiabilidade da aplicação.
