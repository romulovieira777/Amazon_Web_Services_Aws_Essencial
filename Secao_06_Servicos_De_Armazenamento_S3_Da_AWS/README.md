## Seção 06: Serviços de Armazenamento S3 da AWS

- Conceitos de buckets e objetos
- Classes de armazenamento
- Controle de acesso e permissões
- Versionamento e ciclo de vida dos objetos
- Boas práticas de segurança no S3
